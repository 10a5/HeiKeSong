# 实际建筑桥网预览（分散建筑与服务点版）

场景：res://scenes/ActualBuildingBridgePreview.tscn。F6运行，主场景及灰盒场景未修改。

## 地图调整
- 20栋实际建筑改用分散坐标：DISTRIBUTED布局减少连续堆楼；每栋仍占一个12m网格，模型最大水平边约9m。
- 商店和医疗点在固定主道路（x=-6纵向段）均匀交替：商店z=-42、6；医疗点z=-18、30。
- 全图只有一个 `Navigation/Start`，位置(-6,0.2,42)；一个 `Navigation/Goal`，位置(-6,0.2,-42)。小巷死端不算终点。
- 起点和终点各有一条道路接入边界；边界墙只保留这两个道路入口。
- 柏林噪声桥网改为适配新建筑坐标；实际建筑切换seed时保持实例和位置，桥数继续随seed变化。
- 明暗分组仍保留，医疗点/商店优先占用服务格，其他亮色候选不再抢占商店位置。

## 验证
`dispersed_city_services` 通过209项断言：20栋建筑、建筑间不重叠、4个服务点（2商店+2医疗点）、服务点主路坐标、唯一起点/终点、5个seed的桥网范围和场景数据。
运行实测：20栋建筑、4个服务点、唯一开始/结束标记、seed 20260923桥24条；无新运行日志错误。
统计：20260923=26桥，20260924=26桥，20260925=24桥，20260926=24桥，20260927=22桥。
