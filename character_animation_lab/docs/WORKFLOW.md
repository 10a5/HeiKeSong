# 动作制作工作流

## 姿势记录

- 先在 0.0 秒建立基准姿势（通常用 `RESET` 或 `idle` 的第一帧）。
- 每个骨骼只在真正需要的时间点插入旋转关键帧，避免把整条骨架每帧都写满。
- 开启 AnimationPlayer 的循环前，先用一次性动作确认脚底没有漂移。

## 推荐动作采样

| 动作 | 时长 | 关键时间点 |
| --- | ---: | --- |
| idle | 1.0 s，循环 | 0.0 / 0.5 / 1.0 |
| walk | 0.8 s，循环 | 0.0 / 0.2 / 0.4 / 0.6 / 0.8 |
| slash | 0.36 s | 0.0 准备、0.12 命中、0.36 收势 |
| roll | 0.48 s | 0.0 蹲伏、0.22 身体收紧、0.48 起身 |
| dash_slash | 0.42 s | 0.0 蓄力、0.16 位移、0.28 命中、0.42 收势 |

动作最终可以作为 `.tres` 保存，也可以由主项目的 AnimationPlayer 加载并混合。
