# Boss 战胜利演出

每一层击败镜像 Boss 之后播放同一段收尾演出：决战平台崩塌，素子坠入水下的水池，镜头切到水面正上方，雾子仰面漂在水上，屏幕中央浮出“你我犹如隔镜视物，所见无非虚幻迷蒙”，最后数码化的商店闸门吞掉整屏，把本局送进下一层。

演出由两个脚本组成：

| 文件 | 职责 |
| --- | --- |
| `floor_ending.gd` | 3D 部分：崩塌、落水、水面俯视、雾子本体、相机、光照与雾，并负责预载下一层 |
| `ending_overlay.gd` | 屏幕部分：电影黑边、台词、数码商店闸门与进度条；全部用 `_draw()` 绘制，不需要贴图 |

## 流程

| 阶段 | 默认时长 | 画面 |
| --- | --- | --- |
| `collapse` | 2.9 秒 | 决战平台整体下沉并侧倾，碎石与地板碎片从上方与脚下同时崩落，镜头轻微抖动。素子向后倒下，随平台一起坠落 |
| `submerge` | 2.1 秒 | 平台、碎片与素子先后砸进下方水池；素子入水的一瞬间在水面炸开涟漪，镜头停在洞口上方，画面逐渐压黑 |
| `mirror` | 5.8 秒 | 直接切到水面正上方。雾子仰面漂在水上，缓慢起伏、转身，身体两侧不断扩散涟漪；台词淡入、停留、淡出 |
| `digital` | ≥ 2.5 秒 | 绿色数字雨涌起，中央出现写着“接入商店协议”的闸门，下方进度条读取真实加载进度；加载完成后闸门放大并亮成白绿，覆盖整屏 |
| 切换 | 0.55 秒 | 闸门铺满屏幕后调用 `change_scene_to_file()`，下一层加载命中缓存，切换过程看不见 |

合计约 13.5 秒。演出期间鼠标被忽略，**任意键或点击**会跳过崩塌直接看台词，再按一次跳到数码闸门；**R** 仍然保留，立即中断演出并重置本图（环境、HUD、相机、玩家姿势都会还原）。

## 与楼层的关系

演出在 `floor_one.gd` 的胜利判定里启动，所以第一、二、三层共用同一段演出：

- 第一层胜利 → 播放演出 → 第二层；
- 第二层胜利 → 播放演出 → 第三层；
- 第三层胜利 → 播放演出 → 没有下一层，演出结束后把决战场还给玩家继续游玩，并提示“这是目前最深的一层”。

目标场景在演出开始的同一帧就交给 `ResourceLoader.load_threaded_request()`，因此 13 秒的过场期间它早已加载完毕，闸门亮起后的切换只是一次缓存命中，而不是读盘。

## 可调参数

`floor_ending.gd` 的导出属性控制节奏：`collapse_duration`、`submerge_duration`、`mirror_hold`、`digital_min_duration`、`digital_timeout`、`skip_mirror_hold`。台词文本是 `QUOTE` 常量，屏幕文案与进度条在 `ending_overlay.gd` 里。

水池深度是 `BASIN_DEPTH`（水面位于决战地面下方 9 米），平台下沉 `SINK_DEPTH`，素子入水后继续下沉 `PLAYER_SINK`。`SLAB_COUNT` / `DEBRIS_COUNT` 控制地板碎片与碎石数量。

## 实现要点

- **暂停驱动**：演出接管时整棵树是暂停的，游戏节点全部冻结（玩家的 `process_mode` 是 PAUSABLE），因此导演节点使用 `PROCESS_MODE_ALWAYS`，用自己的 `_process(delta)` 显式推进每一个阶段。不依赖物理、计时器或 `await`，所以窗口里、无头测试里、以及中途按 R 之后的表现完全一致。`finish_now()` 是测试用的即时完成钩子。
- **相机取景**：`model/决战场景.glb` 是一座带高墙的圆形建筑，包围盒约 56 × 54 × 67 米，低角度机位会被自己的墙挡住。导演在开场测量所有网格的并集包围盒（`arena_bounds()`），把崩塌机位放在场地内部、角色身后约 9 米处，随角色一起下沉，因此镜头始终在墙内、又不会穿到墙外。
- **水面**：复用 `materials/boss_water.gdshader`，并为它新增 `wave_scale` / `ripple_scale` 两个统一变量（默认 1.0，决战场浅水层行为不变）。俯视时水面的菲涅耳反射最弱，所以演出水池用更高的基础不透明度、放大 2.2 倍的波形和 2.6 倍的涟漪亮度，才不会看起来像一层玻璃。
- **光照与雾**：演出把 WorldEnvironment 临时改成无天空的深夜配色并加浓雾，同时挂一盏偏侧上方的冷色补光——正上方的灯会把高光反射打进俯视画面中央，看起来像水面破了个洞，因此那盏灯刻意偏离天顶。所有环境、灯光、相机 FOV、HUD 与城市小地图的可见性都会在中断时原样还原。
- **雾子**：复用主角的 `character_visual.gd`，去掉刀刃、关闭 AnimationPlayer，按骨骼微调成四肢摊开的躺姿，再整体绕 X 轴放平。模型的有效朝向是角色坐标系的 −Z（见 `player._direction_yaw()`），所以额外转 180° 才能仰面朝天。

## 预览与自测

捕获整段演出的逐阶段截图：

```sh
godot --path . --fixed-fps 60 --script tools/_ending_check.gd
```

脚本会真实打一场决战（侵蚀阈值 → 数字雨 → 决战场 → 致命一击），再按时间点把每个阶段写进 `_visual_check/ending_*.png`。

无头自动检查：

```sh
godot --headless --path . --fixed-fps 60 --script tests/test_floor_ending.gd
```

覆盖台词常量、演出契约、胜利触发、暂停与 HUD 交接、阶段推进（崩塌 → 落水 → 水面 → 数码闸门）、R 中断还原、最深层回到决战场，以及真实切换进第二层场景。
