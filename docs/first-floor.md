# 第一层：水岸街区

默认运行 `floor_one.tscn`。每次进入场景都生成新的随机种子，改变建筑类型的排列、楼高、街道遭遇位置与工厂事件。街道遵循固定的长方形棋盘结构，保证通路连通，不会把功能建筑封在无法到达的位置。

## 尺度

使用原训练场的地砖作为单位：一块地砖为 2×2 米。

| 项目 | 第一版参数 |
| --- | --- |
| 建筑数量 | 5×4，共 20 栋 |
| 建筑占地 | 7×5 块地砖，即 14×10 米长方形 |
| 道路净宽 | 4 块地砖，即 8 米 |
| 相邻街道中心线间距 | X 向 22 米，Z 向 18 米 |
| 路口 | 6×5，共 30 个 |
| 陆地 | 118×80 米，包含四周沿岸街道 |
| 浅水带 | X 向外扩 22 米、Z 向外扩 18 米，包括四角 |
| 浅水深度 | 海床 −0.45 米，水面 −0.12 米 |

建筑地块为长方形，遭遇点属于两个路口之间的街段。居民楼、商店和工厂使用贴合实际 GLB 表面的简化三角面碰撞，保留凹入的墙面、真实开口、台阶及平台，不再用地块大小的盒子包住建筑。模型有实际通道且能容纳角色时才可通过，不会在可见墙面上人为挖出隐形入口。普通走路、翻滚和闪现不会穿过实体墙。摄像机与角色之间的建筑会保留上半部分并变为半透明虚化状态，同时保留底部占地轮廓和碰撞，便于观察玩家。

普通移动可自动上下不高于 **0.30 米** 的小台阶，包括建筑的 0.22 米混凝土底座。攀爬前检查整个角色胶囊的上方和前方空间，低顶、过高墙壁及悬空状态不会触发攀爬；跳跃和卡牌位移沿用原本的运动。模型中的楼梯仍需有足够宽的踏面、合理的级高和头顶空间；本次没有增加进屋场景或攀墙技能。

当建筑挡住摄像机与角色之间的视线时，建筑上半部分不会消失，而是保留在原地并以蓝青色科技渐变、半透明扫描材质显示；材质带有沿楼体移动的扫描线和细网格。进入和离开遮挡状态时会在约 0.18 秒内渐入/渐出，底部用一圈简化轮廓标出占地。这个效果只改变渲染，不改变建筑碰撞、门口交互或地图占地。

遮挡使用独立的楼体表面检测层，不包含较宽的地块底座。每帧更新镜头后，对人物躯干检测九条视线，至少五条被同一栋楼挡住才触发虚化，避免碰到楼边、细小挑檐或简化网格误差时整栋楼变透明。位于镜头近裁剪面之前或人物后方的建筑也不会触发。

居民楼从 `居民楼.glb`、`居民楼(1).glb`、`居民楼3.glb`、`居民楼4.glb`、`居民楼5.glb` 中按地图种子随机选择。每个模型保持比例，长边沿地块长轴放置，自动居中落在 14×10 米底座上；住宅以约 15.2 米为目标高度，再按地块边界限制统一缩放。工厂在 `工厂1.glb` 与 `工业机房楼.glb` 中随机选择，商店使用 `商店.glb`；医疗中心和公安局暂保留灰盒和对应的实体盒碰撞。所有 GLB 作为可遮挡上部纳入同一套虚化和材质恢复流程。

八份碰撞资源位于 `assets/collisions/buildings/`，由原始网格离线简化生成，同款楼共用资源。普通模型约 1.4 万三角面，细节较多的原版居民楼保留 6 万面；运行时不再逐栋处理数十万至数百万面。资源生成方法及误差记录见该目录的 `README.md` 和 `manifest.json`。

### 雨后旧街材质

根据参考图，游戏运行时使用 `materials/weathered_residential.gdshader` 调整居民楼主体：保留顶点色区分的墙面、栏杆和管线，增加冷灰抹灰、剥蚀斑点、竖向雨痕及近地潮渍；窗户分别使用亮、暗两档暖琥珀材质。原始 GLB 文件未被改写，在 Blender 中直接打开不会自动显示这些 Godot 材质。

`materials/wet_street.gdshader` 为道路添加沥青颗粒、裂痕、不规则湿区及粗糙度变化，为人行道添加交错石砖与砖缝；标线也有磨损处理。材质采用世界坐标，不需要给 GLB 补 UV，也不依赖额外图片贴图。第一层的阴天天空提供环境反光，附近四盏无阴影暖光补充窗边的照明。它们不改变碰撞、地块尺度、道路宽度或地图随机规则。

## 随机生成顺序

1. 进入第一层取得新随机种子；测试可以传入固定种子重现布局。
2. 生成连续的陆地、棋盘道路，以及外围浅水海床、回岸缓坡和深水表面。
3. 南侧三格中随机选择商店与医疗中心位置，提供附近的基础服务。
4. 将剩余建筑类型按种子洗牌填入空格；居民楼实例化 GLB，其他建筑随机生成楼高。
5. 从不同街段中随机选出八个遭遇点，避开出生位置。守卫在玩家进入对应街段后开始交战。
6. 按地图种子和建筑 ID 确定工厂事件，同图重试会保留事件类型。

## 建筑交互

靠近发光的门口标记，按 **E**。

| 建筑 | 数量 | 功能 |
| --- | --- | --- |
| 居民楼 | 12 | 阻挡通行，构成街道的墙体；每栋从现有款式中随机选模型 |
| 商店楼 | 3 | 使用 `商店.glb`；支付 20 信用恢复一张尚未解锁的动作牌，全部解锁后可支付 10 信用补满能量 |
| 工厂 | 3 | 使用工厂 GLB；一次随机事件：15 信用、补满能量，或恢复动作牌；牌已齐全时兑换信用 |
| 医疗中心 | 1 | 免费恢复 40 生命，每处一次；生命已满时不消耗次数 |
| 公安局 | 1 | 一次装备箱：恢复一张动作牌并获得 20 信用 |

开局有 40 信用；每场街道遭遇清理后获得 15 信用，同一遭遇不会重复发奖。保留现有四手牌、随机抽牌、弃牌和洗牌规则。

## 水域和控制

浅水内可以站立、走动和跳跃，街道出口有缓坡可直接走回岸上。更外侧的深水没有海床：角色会真实下沉，脚部低于 −2.4 米时进入“意识迷失”，本次探索失败。尚未沉下去时仍可尝试用位移或跃升返回浅水；翻滚避伤不能免除迷失。

浅水和深水共用连续的蓝灰水面，小地图也不再用两种颜色分区；深浅只由海床碰撞和下沉规则区分。`materials/water_surface.gdshader` 使用世界坐标生成流动细波、光影与天空反光。`water_effects.gd` 根据玩家实际接触水面和移动距离产生扩散波纹：走动、翻滚和落水均会扰动水面，腾空或静止时不会持续产生波纹；波纹在 2.2 秒内消散，暂停时冻结，重试或新地图时清空。

- **M** 或点击右上小地图：展开地图，显示建筑类别、街道遭遇和当前位置；查看期间暂停。
- **左键拖动**：水平 360° 旋转，上下可从接近水平调整到接近垂直俯视。**触控板双指张开**拉近，**捏合**拉远；滚轮或双指上下滑动也可缩放，距离范围为 4～85 米。
- **W / A / S / D 或上下左右方向键**：相机相对移动，方向键与 WASD 完全等效。
- **E**：门口交互。
- **R**：以相同种子重试当前地图，复活、重置信用和服务，保留当前会话已解锁的动作牌。
- **N**：立即生成另一张第一层地图，也保留当前会话已解锁的动作牌。
- 关闭游戏后重新启动：进入新的随机第一层，动作恢复为初始三种；暂未做存档。

这版是可探索的灰盒地图，没有室内场景或下一层入口。原训练场保留在 `main.tscn`，可从编辑器单独运行。

## 代码与验证

`first_floor_map.gd` 生成几何和地图数据，`floor_one.gd` 接入玩家、牌库、资源、水域与暂停，`city_building.gd` 处理建筑交互，`street_encounter.gd` 管理街段战斗，`city_overlay.gd` 显示地图。

在项目目录运行：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --fixed-fps 60 --script tests/test_first_floor.gd
```

测试涵盖种子重现与变化、20 栋长方形建筑的分配、14×10 米地块和 8 米街道、街道连通和实际行走、模型表面碰撞与走近凹入墙面、四边四角浅水、上岸缓坡、深水迷失、交互费用和次数、工厂事件、街段遭遇奖励以及暂停与重试。

`tests/test_player_steps.gd` 另行验证多级三角网格台阶上下、高墙、低顶、空中接近台阶，以及翻滚和突进碰撞。
