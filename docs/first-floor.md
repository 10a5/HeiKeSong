# 第一层：水岸街区

默认运行 `floor_one.tscn`。每次进入场景都生成新的随机种子，改变建筑布局朝向、类型、模型、楼高、地面路线、遭遇位置与工厂事件。地图规划移植自 `roguelike_map_handoff`：在 8×8 逻辑网格中放置 20 栋分散建筑，再用 Perlin 噪声权重、Kruskal 连通骨架、支路和 dogleg 折线生成路线。

原 handoff 的建筑坐标固定，随机的是楼间高架桥。此版本额外使用种子选择 8 种旋转/镜像布局，并同步变换商店、医疗点、起终点与街道；不同布局保持 14×10 米长方形地块和模型比例。建筑位置目前来自这 8 种变体，尚未实现任意位置的自由重排。相同种子可完整重现地图。

楼间路线在本项目中投影为实际可见的地面道路，包含每一段折线，小地图同步显示，街道遭遇沿这些路线分布。`bridge_data` 保留原规划点、完整的地面坐标和 8 米高架坐标供后续扩展；当前没有生成真实高架桥、登桥楼梯或下一层入口。模型、表面碰撞、遮挡虚化、贴近建筑按 E 交互与外围水域沿用现有系统。

## 尺度

使用原训练场的地砖作为单位：一块地砖为 2×2 米。

| 项目 | 第一版参数 |
| --- | --- |
| 建筑数量 | 8×8 逻辑网格中的 20 栋分散建筑 |
| 建筑占地 | 7×5 块地砖，即 14×10 米长方形 |
| 道路净宽 | 4 块地砖，即 8 米 |
| 相邻街道中心线间距 | X 向 22 米，Z 向 18 米 |
| 规划道路 | 38 个连通道路单元及其相邻街段；另叠加种子生成的楼间地面路线 |
| 陆地 | 184×152 米，包含分散街区外围道路 |
| 浅水带 | X、Z 向外各扩 18 米，包括四角 |
| 浅水深度 | 海床 −0.45 米，水面 −0.12 米 |

建筑地块为长方形，遭遇点属于规划路线上的街段。居民楼、商店和工厂使用贴合实际 GLB 表面的简化三角面碰撞，保留凹入的墙面、真实开口、台阶及平台，不再用地块大小的盒子包住建筑。模型有实际通道且能容纳角色时才可通过，不会在可见墙面上人为挖出隐形入口。普通走路、翻滚和闪现不会穿过实体墙。商店和工厂不再叠加“商店/工厂”字样、彩色条纹、门口圆环或立牌；这些旧灰盒提示节点已移除，保留 GLB 自带的材质和细节。

商店、工厂、医疗中心和公安局仍响应 E，但服务节点本身不可见。交互距离以对应模型的实际水平包围范围计算，玩家贴近模型外沿约 1.15 米以内即可交互，从旧地块中心或远离建筑的空气位置不能触发。

普通移动可自动上下不高于 **0.30 米** 的小台阶，包括建筑的 0.22 米混凝土底座。攀爬前检查整个角色胶囊的上方和前方空间，低顶、过高墙壁及悬空状态不会触发攀爬；跳跃和卡牌位移沿用原本的运动。模型中的楼梯仍需有足够宽的踏面、合理的级高和头顶空间；本次没有增加进屋场景或攀墙技能。

当建筑挡住摄像机与角色之间的视线时，建筑上半部分不会消失，而是保留在原地并以蓝青色科技渐变、半透明扫描材质显示；材质带有沿楼体移动的扫描线和细网格。进入和离开遮挡状态时会在约 0.18 秒内渐入/渐出，底部用一圈简化轮廓标出占地。这个效果只改变渲染，不改变建筑碰撞、模型附近交互或地图占地。

遮挡使用独立的楼体表面检测层，不包含较宽的地块底座。每帧更新镜头后，对人物躯干检测九条视线，至少五条被同一栋楼挡住才触发虚化，避免碰到楼边、细小挑檐或简化网格误差时整栋楼变透明。位于镜头近裁剪面之前或人物后方的建筑也不会触发。

居民楼从 `居民楼.glb`、`居民楼(1).glb`、`居民楼3.glb`、`居民楼4.glb`、`居民楼5.glb` 中按地图种子随机选择。每个模型保持比例，长边沿地块长轴放置，自动居中落在 14×10 米底座上；住宅以约 15.2 米为目标高度，再按地块边界限制统一缩放。工厂在 `工厂1.glb` 与 `工业机房楼.glb` 中随机选择，商店使用 `商店.glb`，医疗中心使用 `医疗点.glb`；公安局暂保留灰盒和对应的实体盒碰撞。所有 GLB 作为可遮挡上部纳入同一套虚化和材质恢复流程，并与离线简化的模型表面碰撞保持同一套旋转、缩放和居中变换。

九份碰撞资源位于 `assets/collisions/buildings/`，由原始网格离线简化生成，同款楼共用资源。普通模型约 1.4 万三角面，细节较多的原版居民楼保留 6 万面；运行时不再逐栋处理数十万至数百万面。资源生成方法及误差记录见该目录的 `README.md` 和 `manifest.json`。

### 雨后旧街材质

根据参考图，游戏运行时使用 `materials/weathered_residential.gdshader` 调整居民楼主体：保留顶点色区分的墙面、栏杆和管线，增加冷灰抹灰、剥蚀斑点、竖向雨痕及近地潮渍；窗户分别使用亮、暗两档暖琥珀材质。原始 GLB 文件未被改写，在 Blender 中直接打开不会自动显示这些 Godot 材质。

`materials/wet_street.gdshader` 为道路添加沥青颗粒、裂痕、不规则湿区及粗糙度变化，为人行道添加交错石砖与砖缝；标线也有磨损处理。材质采用世界坐标，不需要给 GLB 补 UV，也不依赖额外图片贴图。第一层的阴天天空提供环境反光，附近四盏无阴影暖光补充窗边的照明。它们不改变碰撞、地块尺度、道路宽度或地图随机规则。

## 随机生成顺序

1. 进入第一层取得新随机种子；测试可以传入固定种子重现布局。
2. 按种子选择分散建筑的旋转/镜像变体，生成连通图、可通行道路单元及地面街段。
3. 生成连续陆地、网格道路和楼间地面路线的每一段折线及标线，以及外围浅水海床、回岸缓坡和深水表面。
4. 在 handoff 的服务插槽放置商店和医疗中心，其余建筑类型按种子洗牌填入空格；居民楼实例化 GLB，工厂选择现有 GLB 款式。
5. 从规划器的清晰图边中随机选出八个地面遭遇点，避开出生位置。守卫在玩家进入对应路线后开始交战。
6. 按地图种子和建筑 ID 确定工厂事件，同图重试会保留事件类型。

## 建筑交互

贴近对应建筑模型外沿约 1.15 米内，按 **E**。

| 建筑 | 数量 | 功能 |
| --- | --- | --- |
| 居民楼 | 12 | 阻挡通行，构成街道的墙体；每栋从现有款式中随机选模型 |
| 商店楼 | 2 | 使用 `商店.glb`；数字雨转场后显示三张卡牌和三件义体，可点击购买，装备、卸下和出售已有配件 |
| 工厂 | 3 | 每处一次补给，卡牌与义体各 50%；数字雨转场后，两张不同卡牌选一或放弃，或一件义体选择携带或放弃 |
| 医疗中心 | 2 | 免费恢复 40 生命，每处一次；生命已满时不消耗次数 |
| 公安局 | 1 | 一次装备箱：恢复一张动作牌并获得 20 金币 |

开局有 40 金币；每场街道遭遇清理后获得 15 金币，并通过数字雨奖励界面随机提供两张卡牌选一/跳过，或一件义体选择携带/跳过；同一遭遇不会重复发奖。默认四手牌，义体可增加到最多九槽；继续使用随机抽牌、弃牌和洗牌规则。商店购买期间暂停，商品从虚化逐渐显示；离开再进入保留库存及售罄状态。详见 [义体配件与商店](implants-and-shop.md)。

## 侵蚀与决战

左侧的侵蚀条记录本局认知稳定度。探索时连续移动每满 1 秒增加 1 点，连续静止每满 3 秒增加 1 点；卡牌动作、翻滚和街道遭遇战期间暂停累计。成功进入医疗中心、工厂或商店各增加 10 点，公安局和失败交互不会增加。达到 100 后会在当前奖励/商店界面关闭后播放 Matrix 数字雨，隐藏第一层并载入决战场。

决战场复用 `model/决战场景.glb`，玩家保留当前生命、能量、牌库和义体。镜像 Boss 使用相同主角模型和独立骨骼，开局有 3 秒蓝色护盾无敌入场；Boss 有独立生命、能量与护盾显示，并会使用翻滚连拳、突进回旋踢和近身护盾。决战中侵蚀每秒减少 1 点，归零后停在 0，战斗继续进行。按 **R** 可在转场或决战中重置并返回新的第一层起点。

敌人与工厂的卡牌、义体奖励均在绿色数字雨转场后显示，选择期间暂停战斗。卡牌可包含已知动作，领取增加一张独立副本并加入抽牌堆；义体有空位时自动装备，五槽已满时放入背包。放弃不会获得物品，也不返还领取机会。同时击败多个敌人会依次展示各自奖励。奖励种类和内容随地图种子与来源编号固定，不受击败顺序影响。

## 水域和控制

浅水内可以站立、走动和跳跃，街道出口有缓坡可直接走回岸上。更外侧的深水没有海床：角色会真实下沉，脚部低于 −2.4 米时进入“意识迷失”，本次探索失败。尚未沉下去时仍可尝试用位移或跃升返回浅水；翻滚避伤不能免除迷失。

浅水和深水共用连续的蓝灰水面，小地图也不再用两种颜色分区；深浅只由海床碰撞和下沉规则区分。`materials/water_surface.gdshader` 使用世界坐标生成流动细波、光影与天空反光。`water_effects.gd` 根据玩家实际接触水面和移动距离产生扩散波纹：走动、翻滚和落水均会扰动水面，腾空或静止时不会持续产生波纹；波纹在 2.2 秒内消散，暂停时冻结，重试或新地图时清空。

- **M** 或点击右上小地图：展开地图，显示建筑类别、街道遭遇和当前位置；查看期间暂停。
- **左键拖动**：水平 360° 旋转，上下可从接近水平调整到接近垂直俯视。**触控板双指张开**拉近，**捏合**拉远；滚轮或双指上下滑动也可缩放，距离范围为 4～85 米。
- **W / A / S / D 或上下左右方向键**：相机相对移动，方向键与 WASD 完全等效。
- **E**：在商店、工厂、医疗中心或公安局模型外沿附近交互。
- **I** 或左侧“义体 x/5”：查看背包和当前强化，装备或卸下配件；出售需在商店操作。
- **R**：以相同种子重试当前地图，复活、重置金币和服务，保留当前会话已解锁的动作牌。
- **N**：立即生成另一张第一层地图，也保留当前会话已解锁的动作牌。
- R / N 都清空本局购买及敌人、工厂奖励的卡牌和义体配件，取消尚未选择的奖励，恢复四手牌和 40 金币；保留旧记忆终端/公安局赠予的动作卡，领取恢复的图鉴知识不转换为免费卡牌。
- 关闭游戏后重新启动：进入新的随机第一层，动作恢复为初始五种；暂未做存档。

这版是可探索的灰盒地图，没有室内场景或下一层入口。原训练场保留在 `main.tscn`，可从编辑器单独运行。

## 代码与验证

`roguelike_map_layout.gd` 负责不依赖模型的种子规划，`first_floor_map.gd` 生成几何和地图数据，`floor_one.gd` 接入玩家、牌库、资源、水域与暂停，`city_building.gd` 处理建筑交互，`street_encounter.gd` 管理街段战斗，`city_overlay.gd` 显示地图。

在项目目录运行：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --fixed-fps 60 --script tests/test_first_floor.gd
```

`tests/test_roguelike_layout.gd` 独立验证 64 个种子的布局变化、复现、服务分配和实际图连通性。第一层集成测试涵盖规划器的种子重现、20 栋分散建筑、图连通性、道路和地面遭遇适配、14×10 米地块、模型表面碰撞与走近凹入墙面、四边四角浅水、上岸缓坡、深水迷失、交互费用和次数、工厂事件、街段遭遇奖励以及暂停与重试。

`tests/test_erosion_system.gd` 验证移动/静止计时、战斗暂停、设施加值、100 点阈值、Boss 每秒排空和重置；`tests/test_erosion_flow.gd` 验证第一层到 Matrix 转场、决战场出生、Boss 入场无敌、牌库/义体保留、归零和 R 中断；`tests/test_boss_arena.gd` 验证 GLB 场地碰撞、镜像 Boss 连招、护盾与地面稳定性。

`tests/test_player_steps.gd` 另行验证多级三角网格台阶上下、高墙、低顶、空中接近台阶，以及翻滚和突进碰撞。
