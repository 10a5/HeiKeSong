Godot · 实时动作 · 卡牌构筑 · Roguelite

《神经断层》
游戏执行指南

把“抓牌构筑”变成身体动作，把 Boss 的“读心”变成可观察、可反制的系统。此文档只定义制作路径与验收门槛，不启动游戏开发。

状态：概念验证前引擎：Godot 4.x首要目标：验证手感LLM：最后接入
01 / PRODUCT NORTH STAR

先锁定游戏承诺

牌不是菜单，是动作

打出卡牌立即驱动角色出拳、射击、翻滚或突进斩。选择牌与空间操作必须同时成立。

构筑的是身体节奏

玩家不是只堆倍率，而是在攻击部位、位移方向、能量窗口之间形成战斗“签名”。

Boss 学习但不作弊

Boss 根据可解释的统计形成反制倾向，所有预判都先给视觉信号，并允许玩家故意误导。

原创化边界“赛博义体、网络人格、身份危机”可以继续探索；但正式项目应使用原创世界观、人物、Boss 名、视觉语言、台词与剧情。不要直接使用《攻壳机动队》名称、“傀儡师”角色、公安九课标识或具体情节。本文以工作名“镜像体 / MIRROR”替代 Boss。

一句话版本

在一座持续重写意识的网络都市中，玩家用实时恢复的能量打出“身体动作卡”，改造六个义体部位，并通过刻意改变战斗习惯，反制一个会学习其节奏的镜像智能。

02 / CORE LOOP

一局的完整闭环

01 探索进入短房间，读取地形与敌人配置
02 抓牌战中补牌，决定当下动作序列
03 执行消耗能量，卡牌驱动实时动作
04 改造战后选牌、删牌或升级义体
05 入侵压力阈值触发镜像幻境战
06 留痕Boss 伤害累计，外界干扰下降
推荐节奏普通房间 45–90 秒 → 奖励 10–20 秒 → 每 3–4 个房间触发一次 30–60 秒幻境交锋。首次原型只做“训练场 + 1 小怪 + 1 次幻境”。
胜负与长期进度
  • 本局失败：肉体生命归零，或幻境中的“自我完整度”归零。
  • 阶段成功：在幻境中对 MIRROR 造成伤害并撑到精神恢复计时结束；伤害永久记入本局 Boss 总生命。
  • 局内推进：每次成功直面 MIRROR，外界敌人的“网络增幅”降低一档。
  • 最终胜利：累计击穿 MIRROR 的多个人格层，而不是一次爆发击杀。
03 / CARD LANGUAGE

三类牌，统一执行语法

类型职责费用起点代表牌
攻击造成伤害、破甲、打断1–3直拳 / 点射 / 下劈
位移跑图、闪避、抢位1–3翻滚 / 短闪 / 蹬墙
复合位移与攻击一体，压缩操作窗口4–7突进斩 / 滑铲射击 / 闪身肘击
定价原则复合牌的费用不简单等于“攻击牌 + 位移牌”。它还获得压缩执行时间、降低失误和创造无敌窗口的价值，因此通常再加 1 点“便利税”。

输入与打牌方式建议
  • 保留 4 张可见手牌，对应 1–4 或肩键；不弹出全屏卡牌菜单。
  • 移动保持 WASD / 左摇杆；瞄准保持鼠标 / 右摇杆。打牌只提交动作。
  • 牌打出后进入短执行锁，但允许在明确取消窗口衔接下一张。
  • 抽牌不打断实时战斗；牌从牌库补入空槽。
  • 首个原型不做复杂稀有度、元素、套装与随机词缀。
04 / CYBERNETIC BODY

义体部位要改变“能做什么”

头部

锁定、弱点扫描、预警；避免直接加伤害。

左臂 / 右臂

分别承载近战、枪械、格挡；受损时相关牌变贵或变慢。

左腿 / 右腿

翻滚、冲刺、蹬墙；单腿受损改变方向性与距离。

中枢

能量上限、恢复、抽牌节奏；高收益也最危险。

避免六条独立血条原型阶段用“部位状态：正常 / 过载 / 损坏”即可。否则玩家要同时管理手牌、位置、能量和六个血条，认知负担过高。
推荐的部位—卡牌关系
  • 每张动作牌绑定一个主执行部位；复合牌可绑定两个。
  • 过载：该部位卡费用 +1，持续 4 秒；损坏：该部位卡不可用，直到修复节点。
  • 可装备“交叉布线”义体，让右臂牌在左臂执行，但伤害降低，形成容错构筑。
  • 敌人攻击通过颜色 + 图标说明将打击哪个部位，给玩家针对闪避的理由。
05 / ADAPTIVE BOSS

MIRROR：先可解释地学习，再开口说话

战斗事件→玩家画像→策略分类→反制权重→Boss 卡组→预警表现

L0 固定招式

基础状态机，保证无数据、无网络也能完整战斗。

L1 行为画像

统计最近 30–60 秒：距离偏好、能量区间、连续牌型、闪避方向、部位依赖。

L2 规则反制

从有限模块中调权重：封位、诱导闪避、部位压制、能量惩罚；不生成未知能力。

L3 LLM 台词

只接收压缩后的安全标签，生成短评；不参与伤害、命中、抽牌或胜负判定。

玩家画像与对应反制
特征示例反制
惯用距离近 / 中 / 远调整压迫与封锁权重
闪避方向左 62%左侧延迟攻击
低能量习惯常降至 2 以下充能提示后追击
部位依赖右臂牌 48%威胁右臂，逼迫备用路线
连牌模板翻滚→射击假前摇诱导后延迟格挡
“窥探”如何做到公平
  • Boss 只能使用玩家已经暴露过的模式，不能读取当前手牌或未来随机结果。
  • 策略切换前用扫描线、语音关键词和姿态变化说明“它学到了什么”。
  • 预测保留误差与 20–30% 非针对性行为，避免硬作弊。
  • 玩家连续两次改变行为后，旧画像应衰减，奖励“反读心”。
  • 战后显示：“检测到左闪倾向 62%，部署侧向封锁。”
幻境强制战的职责
  • 触发：精神压力到阈值或完成固定房间数，不纯随机打断。
  • 目标：存活至精神恢复，同时尽可能造成累计伤害。
  • 变化：弱化地形复杂度，突出出牌节奏与 Boss 学习结果。
  • 外界回报：每突破一层人格防火墙，普通敌人的网络增幅 -1 档。
  • 防挫败：幻境失利先给予“人格裂痕”，累计后才结束整局。
LLM 红线不要把实时战斗决策交给 LLM：延迟不可控、难复现、难平衡，也可能离线失效。台词要有超时（建议 800ms）、过滤、缓存与模板降级；失败时不影响战斗。

卡牌执行管线
func try_play(card: CardData) -> PlayResult:
  if not body_rig.can_use(card.body_part): return PART_BLOCKED
  if energy.current < card.energy_cost: return NO_ENERGY
  if not state_machine.can_accept(card.tags): return BAD_STATE
  energy.spend(card.energy_cost)
  var action = card.action_scene.instantiate()
  action.setup(actor, card)
  action.finished.connect(_on_action_finished)
  add_child(action)
  telemetry.record_card_play(card)
  return OK

CardData 只描述数据；Action 负责执行；角色状态机决定是否可接收。不要在 UI 卡牌脚本中直接写伤害和位移。

必须埋点的 8 个指标
  1. 每分钟打牌数与未打出尝试数
  2. 能量在 0–2 / 3–7 / 8–10 的时间占比
  3. 三类牌的选择率、命中率与取消率
  4. 每个义体部位的使用占比
  5. 受到伤害前 1 秒玩家最后动作
  6. 幻境中存活时间与累计伤害
  7. Boss 预测准确率，以及玩家成功误导率
  8. 玩家能否复述“Boss 为什么这样反制”
08 / STAGED DELIVERY

按风险排序，而不是按内容堆量

P0

纸面模拟

用表格模拟 10 张牌、能量恢复与 30 秒战斗。验证费用、手牌和动作频率。

出口：三类牌各有明确用途，复合牌不是永远最优。

P1

灰盒手感

Godot 训练场：移动、1 个木桩、4 张手牌、能量条、攻击/翻滚/突进斩各 1 张。

出口：测试者 3 分钟内无需说明即可打牌、移动、恢复能量。

P2

战斗垂直切片

10 张起始牌、1 种小怪、1 个房间奖励、3 个义体状态；加入命中停顿和明确前摇。

出口：5 分钟流程可开始、战斗、奖励、结束、重开。

P3

固定 MIRROR

先做固定 Boss 卡组和 45 秒幻境；Boss 伤害可累计，外界增幅可下降。

出口：幻境循环本身好玩，即使 Boss 完全不会学习。

P4

规则自适应

接入画像与 3 种反制模块；展示“检测—预警—执行—结果”的证据链。

出口：玩家能故意改变习惯，并让 Boss 的反制落空。

P5

构筑深度

扩至 24–30 张牌、6 部位、升级/删牌、3 种小怪和分叉奖励。

出口：至少 3 种打法，且没有单牌选择率长期超过 70%。

P6

LLM 评论层

只传事件摘要与标签，加入缓存、限时、过滤、模板降级和离线模式。

出口：断网或超时不影响一帧战斗；台词不泄露隐藏信息。

09 / VERTICAL SLICE SCOPE

首个可玩版本：做什么 / 不做什么

必须有

  • 1 个训练房间
  • 1 个近战小怪
  • 6 张动作牌
  • 4 手牌与 10 能量
  • 3 个义体部位状态

10 / RISK REGISTER

优先消灭致命风险

高风险
实时动作与随机手牌互相打架

保证基础位移不依赖抽牌，或设置“紧急翻滚”保底；先测试可读性再扩牌。

高风险
自适应 Boss 被感知为作弊

禁止读当前手牌；展示画像证据；提供反读心奖励和画像衰减。

高风险
系统过多导致原型无法收敛

执行 P1–P3 门槛；固定 Boss 不好玩前，禁止接入学习与 LLM。

中风险
部位系统只剩数值惩罚

升级应解锁动作或改写卡牌语法，而不只加百分比。

中风险
题材与既有 IP 过近

工作名、角色轮廓、组织、术语、UI 图形和叙事冲突全部原创化；商业化前做专业 IP 审查。

12 / FIRST PLAYTEST

第一次可玩测试的通过标准

维度通过线
理解4/5 测试者能在 3 分钟内说清三类牌差别
操作4/5 能完成“翻滚躲避 → 射击反击”而无需提示
能量玩家能预测下一张牌何时可用；无长期空等
构筑奖励三选一时，玩家能说出选择与打法的关系
幻境至少 3/5 愿意立刻再打一次，并理解累计伤害意义
稳定性可开始、暂停、结束、重开；无控制台阻断错误
首轮只回答一个问题“用卡牌触发实时身体动作，是否比传统按键更有策略乐趣？”如果答案不明确，不要用更多卡牌、剧情或 AI 掩盖核心问题。
执行顺序：纸面模拟 → 灰盒手感 → 固定幻境 → 可解释自适应 → 构筑扩容 → LLM 台词。任何阶段未达到出口标准，都回到本阶段调整，不以增加内容代替验证。
